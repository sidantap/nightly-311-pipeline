Data quality

Rows that break a rule never reach the dashboards. They're held in a quarantine table with the reason, and dbt tests stop the run if anything downstream looks wrong.

Why rows were held

quarantine, all time

Checks on every run

dbt tests and freshness
  • Unique, not-null keys
    Request numbers, weather dates, complaint IDs and every dimension key.
  • Accepted values
    Request status groups and categories come from a fixed list.
  • Relationships
    Every fact row points at a real request type and date.
  • No negative durations
    Days to close can't be below zero.
  • Incremental loads
    Each source loads only what changed since its watermark, with a small overlap for late updates.

Complaint model

Reads the free-text description of each new NHTSA vehicle complaint and predicts which part of the car it's about. NHTSA's own component tag is the answer key, so it's scored every night on complaints it has never seen.
