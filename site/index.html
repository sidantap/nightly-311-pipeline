Nightly 311 pipeline

Every night GitHub Actions pulls new Cincinnati 311 service requests, NOAA weather and NHTSA vehicle complaints. It lands them as received, cleans and tests them with dbt, routes bad rows to quarantine, classifies new complaints with an open-source model, and rebuilds this page. Cost to run: $0. Complaint classifier

Reads the free-text description of each new NHTSA vehicle complaint and predicts which part of the car it's about. NHTSA's own component tag is the answer key, so the model is scored every night on complaints it has never seen.
